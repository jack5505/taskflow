# deploy/ — скрипты стенда

Полная инструкция — [docs/DEPLOY.md](../docs/DEPLOY.md): переменные окружения, первый запуск, миграции, администратор, обновление и откат, бэкап, восстановление и ежемесячная проверка. Скрипты читают `.env` из корня репозитория и работают с compose-проектом `COMPOSE_PROJECT_NAME`.

| Скрипт | Что делает |
|---|---|
| `deploy.sh vX.Y.Z` | выкладка образа из GHCR, ожидание `/health`, автоматический откат на предыдущий образ |
| `backup.sh [метка]` | дамп PostgreSQL, архив вложений и секретов (`.env`, `secrets/`) в `BACKUP_DIR`, ротация 30 дней, копия в `BACKUP_REMOTE` |
| `restore.sh <метка>` | восстановление стенда из бэкапа (данные стенда заменяются, с подтверждением) |
| `restore-check.sh [метка]` | проверка бэкапа во временных контейнерах, стенд не трогает; итог — в `BACKUP_DIR/CHECKS.md` |
| `install-timers.sh` | systemd-таймеры: бэкап ежедневно в 03:30, проверка восстановления 1-го числа в 05:00 |
| `lib.sh` | общая часть: чтение `.env`, имена, лог |
| `nginx/` | конфиг сайта для nginx сервера |
