# web/ — веб-интерфейс

Общие правила — в корневом `CLAUDE.md`. Здесь — то, что касается фронтенда.

## Стек и команды

React 18, TypeScript, Vite, TanStack Query, dnd-kit для перетаскивания. Линтер — oxlint.

```
npm ci            установка
npm run dev       Vite, /api проксируется на localhost:8100
npm run lint      oxlint
npm run build     tsc -b && vite build → ../api/internal/web/dist (встраивается в бинарник Go)
```

Сборка пишет в `api/internal/web/dist`; в git там только заглушка `index.html`, остальное игнорируется.

## Правила

- Экраны — по ТЗ §7 (восемь экранов) и ничего сверх: вход, проекты с «Моими задачами», доска, бэклог и спринты, карточка задачи, отчёты, профиль, настройки проекта с шестью вкладками.
- Запросы к API — только через сгенерированный из Swagger клиент (issue #4), не через ручные `fetch`. Состояние сервера — TanStack Query; глобальный стор не заводить.
- Авторизация: access-токен в памяти, refresh в httpOnly cookie, автообновление по 401 (§9.1). Токен в localStorage не хранить.
- Права из §2 дублируются в интерфейсе только для скрытия кнопок; настоящая проверка — на сервере. Кнопка, которую сервер отклонит, не показывается.
- Markdown (описание, комментарии) рендерить с санитайзингом, сырой HTML запрещён (§10.3).
- Даты показывать как `dd.mm.yyyy`, время — в поясе пользователя из профиля (§7). Длительности — в формате `2h 30m` (§6.1).
- Фильтры доски хранятся в URL (§7.3): перезагрузка страницы их не теряет.
- При `409 VERSION_CONFLICT` показывать чужие правки и предлагать повторить, не перезаписывать молча (§3.3).
- Язык интерфейса только русский (§10.3); тексты без зависимости от рода пользователя.
- Ширина от 1024 px; мобильную вёрстку не делать (§7).

## Тесты

Vitest для логики (парсеры, форматирование), Playwright для сценариев приёмки из §10.4 (issue #46). E2E гоняются в CI; локально Chromium на сервере не стартует — запускать в образе `mcr.microsoft.com/playwright`.
